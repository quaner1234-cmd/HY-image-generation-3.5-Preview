## 一、选的那一张

**`references/ChatGPT Image Sep 28, 2026, 04_32_33 PM.jpg`**（1152×1536，秋末傍晚菜地：卷云落日压在地平线上、前景大片叶菜、菜畦垄沟、中景一棵独立大树、地平线防风林带与村舍、远处高压铁塔、田间一小块红色农机）

为什么是它（对照这次的目标）：

- **有真实且明确的光源**：落日贴着地平线并被树冠部分遮挡 → 天然逆光，是"光感优先"成立的前提；
- **有可组织笔触的大面积近景**：叶菜是印象派最爱的短笔触素材，菜畦垄沟又提供重复的透视节奏；
- **色彩结构天然分层**：金橙（天空）／橄榄绿（田与菜）／灰紫（远景），冷暖关系是现成的；
- **视觉重心现成**：落日 + 大树，不需要重新构图就能立住焦点；
- **光在衰减**：天空亮、地面暗，画面自带明度阶梯。

第二选择：`…04_32_09 PM.jpg`（横版暮色，天空更戏剧、横版更合社媒），但前景整片压黑——绘画时地面只能靠概括甚至编造，风险更高。

## 二、四个方向

同一张照片、同一张参考图、同一套底线，只替换 prompt 中"画面决策"的部分：

| 目录 | 方向 | 这个方向押注什么 |
|---|---|---|
| `01-light/` | 光感优先 | 让光本身当主角：逆光、光雾的浓淡衰减、地面压在阴影里但保留层次，亮部不许用白直接画 |
| `02-color/` | 色彩优先 | 暖冷两大声部的呼吸：压低饱和度、靠明度与冷暖取胜、同一种绿要有温度差、小面积亮色只作克制音符 |
| `03-brushwork/` | 笔触优先 | 笔触当骨架：厚薄疏密**按区域分别组织**、边缘虚实有别、避免画面处处同等密度的笔触 |
| `04-completion/` | 整体完成度优先 | 三层空间 + 明度阶梯 + 主次分配，每个角落处理到位，读起来是"画完的作品"而不是习作 |

每份 prompt 的组织方式（按你的要求）：**视觉重心 → 光线与空气感 → 色彩关系 → 笔触组织 → 哪些概括／哪些必须保留辨识度**，最后是一份四份共享的底线：

- 保留地点身份、视点与地平线，不制造镜头感；
- 照片里的现实元素（土地、田垄、树、村舍、电线杆、高压铁塔）是这个地点的真实身份，如实存在，不刻意清除；
- 不幻想化、不欧式乡村化、不滤镜感／塑料感、不过度甜美、不纪念品装饰画感、不逐物体描边、无文字边框水印；
- 明确写了"不是在照片上覆盖一层油画纹理"——要的是归纳、取舍与重新组织的绘画决策。

prompt 原文：各目录下 `prompt.txt`。
