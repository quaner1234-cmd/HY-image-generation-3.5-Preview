## 三、共同遵守的约束（写进了每份 prompt）

- 以照片为唯一依据：构图、视点、地平线高度、物体位置与大小关系全部保持原样；
- 不添加原照片中不存在的元素（山、河、湖、海、森林、城堡、欧式庄园、新房屋、人物、牲畜、鸟群…）；
- 不欧化、不幻想化，不做仙气/梦幻光效，不要巨大日轮光晕与星空；
- 不出现文字、字母、数字、印章、签名、边框、画框、水印、logo；
- 不给平坦的华北平原土地加丘陵起伏；土路不许变成石板路/水泥路，村舍不许变成欧式建筑。

两版差异只在"绘画处理"段：保守版保留原图光色与明度关系、只做笔触概括；表现版强化空气透视、碎笔触色彩并置、暗部去黑（用深紫/深蓝绿）、天空与地面做光雾与呼吸感。
