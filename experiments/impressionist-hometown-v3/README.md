## 二、四条复刻路线

同一张照片（`references/ChatGPT Image Sep 28, 2026, 04_32_33 PM.jpg`）、同一套底线，区别只在"怎么复刻"：

| 目录 | 路线 | 提交的参考图（按顺序） |
|---|---|---|
| `01-photo-plus-style-ref/` | 照片 ＋ 最对口的那张风格图，prompt 里明确分工：内容照照片、绘画语言照风格图 | 照片 ＋ `style-…AM-5`（同一场景的油画版） |
| `02-boost-over-ref/` | 同一组参考图，但要求把绘画强度**推到比风格图更进一步**（笔触更果断、色彩更凝练、光更明确） | 照片 ＋ `style-…AM-5` |
| `03-text-only-style/` | **不给风格图**，只把上面那套绘画语言写成文字，用来检验"文字够不够" | 照片 |
| `04-two-style-refs/` | 照片 ＋ **两张**同族风格图（不同地块），要求提炼它们共同的绘画语言 | 照片 ＋ `style-…AM-5` ＋ `style-…AM-4` |

风格参考图是你给的 PNG 的等比例副本（长边 1024、JPEG q92，约 360–400 KB／张），放在 `references/style-refs/`（与原始照片一样**不入库**），压缩只是为了压住上传体积——原因见 `PARAMS.md` 第 4 节。

每份 prompt 的写法：先说清参考图分工 → 列出要落实的绘画语言（笔触／色彩／光／空气透视／完成度）→ 最后是四份共享的底线（保留地点身份与视点、现实元素如实存在、不幻想化、不欧式乡村化、不滤镜感、不过度甜美、不逐物体描边、无文字边框水印）。
