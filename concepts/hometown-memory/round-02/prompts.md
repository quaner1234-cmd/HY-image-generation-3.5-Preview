# Hometown Memory / 故乡记忆 — Round 02 提示词与方案设计

> 实验轮次：Round 02  
> 核心目标：**验证“表达能否脱离原照片成立”**。  
> 约束条件：
> 1. **严禁使用任何实拍照片作为 `--ref` 输入**。本轮纯文生图（text-to-image）。照片仅作为前期 research 素材。  
> 2. 生成结果不能与任何一张原照片形成明显一一对应（杜绝“照片4的同一条路+同一根电线杆+同一座塔”此类重建）。  
> 3. 从**记忆机制**出发提炼 4 种真正不同的表达，而非 4 张原图的变体。  
> 4. 保留克制、低饱和、多色层、纸张纤维、轻微旧化等艺术语言，不带文字与多余符号。  
> 5. 评审硬性指标：**“如果把原始照片放在旁边，这张图是在表达同一种记忆，还是只是在模仿其中一张照片？”** 若为后者则淘汰。

## 方案 A 提示词（归途：通向生活过的地方）
```text
一幅充满克制记忆温度与真实乡村气息的当代艺术绘画，主题为“归途的岔路口”。画面表现北方村落边缘一条普通的水泥硬化路与泥土碎石小道交汇的分岔处，路面带有真实农用车辆压过的浅灰泥痕与细小裂纹，绝非整洁的公园绿道。小道一侧立着一根带斜拉钢丝的旧木质电线杆，几根细弱电线伸向村庄方向。路边生长着耐旱的野蓬草与浅绿杂草，中景掩映在几株高大挺立的白杨树下，远处地平线处隐约露出一两座普通红砖平房的屋顶轮廓，上方升起一缕似有若无的清淡炊烟。
艺术语言融合低饱和度纪实水彩与温和蛋彩质感，色调为沉静内敛的灰青、浅褐泥土色、灰绿与薄暮微光；画面保留细腻的哑光手工纸张纤维肌理与岁月洗礼感。极度安静、平凡、克制。
严厉限制：绝对不出现宏大山脉、峡谷、河流、城市天际线、红旗、纪念碑、欧式农庄、科幻光效或高压铁塔；画面中绝对不要出现任何人物、文字、字母、数字、标题、边框、相框或水印。
```

## 方案 B 提示词（锚点：不变的记忆坐标）
```text
一幅极具泥土真实感与岁月凝固气息的艺术画作，表现乡村田野边界处一座经历数十年风雨的“老机井房与水渠”。画面中心坐落着一座极其普通的旧红砖平顶机井小屋，红砖有些许风化斑驳与浅灰水泥修补痕迹，屋旁伴生着一棵枝干苍劲、树皮粗糙的老槐树，树干微微倾斜，静静守护在田边。小屋下方延伸出一段水泥灌溉水渠，渠边长满干燥的枯草与细小杂灌木。四周是宽阔平缓的冬日休耕土地，土壤呈厚重的黄褐色，质感粗砺踏实。天空是开阔宁静的浅灰蓝与极淡的柔白云层。
画风借鉴细腻的当代写实水彩与浅色矿物颜料设色，低饱和度，带有温和的手工纸张纹理与轻微旧化感；色彩沉稳克制：砖红、灰褐、枯草黄、冷灰青。画面传递出一种故乡永恒不变、无论何时回来都静静立在那里的精神锚点感。
严厉限制：绝对不要奇峰奇石、瀑布、大江大河、城堡、繁复雕塑或过度艳丽的光芒；画面中绝对不要出现任何人物、文字、汉字、字母、数字、印章、边框或水印。
```

## 方案 C 提示词（时刻：该回家的那一刻）
```text
一幅深沉而宁静宽广的当代艺术绘画，表现平原村庄在日落彻底隐没、夜幕初降那一刻的“回家时间感”。画面从村庄后巷或田埂边缘望去，前景是一堵斑驳质朴的黄土砖土墙与一堆整齐码放的干燥玉米秸秆垛，墙边安静倚靠着一辆带着生锈痕迹的旧二八大杠自行车后架，屋檐下挂着两串风干的黄玉米棒。中景是村落错落起伏的灰瓦民居屋顶剪影，一缕极轻薄的淡蓝炊烟在渐凉的晚风中缓缓消散。天空呈现极具时间流逝感的深邃层次：从地平线尽头极狭窄的一抹暗橘红与灰紫微光，平滑过渡到上方大面积幽深广袤的暮色黛蓝与冷灰青。
整体风格融合纪实胶片光影与纸本水彩画的细腻沉淀感，暗部沉稳通透，保留温润的纸质微粒感，充满“天黑该回家吃晚饭了”的日常心理唤醒。
严厉限制：严禁现代都市霓虹、宽阔马路、华丽灯火、红旗、烟花、科幻光束；画面中严禁出现任何人物、文字、字母、数字、标题、相框或水印。
```

## 方案 D 提示词（痕迹：长期生活的器物与土地）
```text
一幅充满亲切泥土温度与朴素劳作痕迹的写实艺术作品，专注表现乡村田埂角落“人刚离开不久的土地痕迹”。画面近景特写一块精心打理过的菜畦转角：湿润深褐的泥土被整齐起垄，垄边插着一把磨得发亮但木柄粗糙斑驳的老铁锹，铁锹柄上搭着一只洗得褪色的蓝白条纹线手套；旁边的一垄蒜苗整齐青翠，一部分地垄覆着一块被砖头压角的旧深色防雨塑料布，布角在微风中轻压在泥土上。中景是平整延伸的田垄与一道简易木栅栏，远景是平坦的地平线与沉静的傍晚漫射光。
画面质感如同一张经过岁月洗礼的哑光手工纸水彩画，色彩极为真实克制：深土褐、青葱绿、铁锈灰、旧布暗蓝与天光淡金，保留纸张纤维的微弱触感，没有人物出现，却处处无声证明着这里被人们细致、勤劳、日复一日地生活与耕作着。
严厉限制：绝对不要奇幻田园、欧式农庄、巨大花海、红旗、城市建筑；画面中绝对不要出现任何人物、文字、字母、数字、印章、相框或水印。
```
