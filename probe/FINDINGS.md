# Hy Image 3.5 preview — 实测能力基线

> 采集日期：2026-09-26（活动窗口第 2 天）
> 方法：直接调用 GMI Cloud `hy-image-v3.5-preview`，本机 Vision 框架 OCR 客观验证文字。
> OCR 关闭语言纠错（`usesLanguageCorrection = false`），否则 OCR 会用语言模型
> "猜"出正确拼写，掩盖真实渲染缺陷。

## 1. 工具与状态

| 工具 | 状态 | 说明 |
|---|---|---|
| `gen.py` | ✅ 可用 | 生图 CLI，支持 prompt / size / 参考图(≤5) / max-pixels |
| `ocr` (Swift+Vision) | ✅ 可用 | 本地客观文字验证，无语言纠错 |
| `eval.py` (Gemini 视觉) | ❌ 不可用 | 返回 `402 Insufficient balance`，账户余额不足。代码路径已验证正确（返回 402 而非 400），充值后可用 |

主模型（Space Bunny）不支持读图，账户无余额跑视觉模型 —— 因此**版面美感、构图、色彩无法自动评判，需要人眼看**。OCR 只解决"文字对不对"。

## 3. 文字渲染实测

### 3.1 明确要求渲染的文字

| 要求 | OCR 实测 | 置信度 | 判定 |
|---|---|---|---|
| `MIDNIGHT STANDARD` | `MIDNIGHT` / `STANDARD` | 0.50 | ✅ 正确 |
| `OCT 1 — NOV 30` | `OCT 1 - NoV 30` | 0.30 | ❌ **NOV → NoV** |
| `月相之间` | `月相之间` | 1.00 | ✅ 正确 |
| `2026 视觉志 第七期` | `2026视觉志第七期` | 0.50 | ✅ 正确（分隔符丢失） |
| `EVAPORATION` | `EVAPORATION` | 1.00 | ✅ 正确 |
| `CONDENSATION` | `CONDENSATION` | 1.00 | ✅ 正确 |
| `PRECIPITATION` | `PRECIPITATION` | 1.00 | ✅ 正确 |
| `COLLECTION` | `COLLECTION` | 1.00 | ✅ 正确 |

**明确要求的文字：8 项中 7 项正确（87.5%），中文 4/4 全对，英文 3/4。**

### 3.2 模型自行添加的文字（prompt 未要求）

| 实测 OCR | 说明 |
|---|---|
| `GMT+8` | 凭空出现，疑似时区/locale 串味 |
| `VOL. 01` | 凭空出现的期号 |
| `XIX` / `THE MILK` | 塔罗牌编号 + **MOON → MILK 严重错字** |
| `WATER CYCLE` / `INFLOGRAPHIC POSTER` | 自加标题，**INFOGRAPHIC → INFLOGRAPHIC** |
| C 图四段说明文字 | 自加英文短句，语法正确 |
| D 图英译句 | 自加中英对照，翻译正确 |

**模型自加文字中至少 3 处硬伤。**

## 4. 结论（仅限已测事实）

1. **中文文字渲染显著优于英文。** 中文 4/4 正确且两次拿到 1.00 置信度；英文在同等字号下出现 `NoV`、`INFLOGRAPHIC`、`MILK` 三种错拼。
2. **错误集中在"模型自加文字"上。** 明确要求的文字 87.5% 正确，自加文字错误率明显更高。模型倾向于自作主张补装饰性文字。
3. **短标题比长句子稳。** 单词级标签（EVAPORATION 等）全部 1.00；含小写/连写的短句（NoV 30）出错。
4. **2K 可用**，2048² 正常返回，中英文长句渲染均正确。
5. **存在不可控的额外文字注入**，OCR 置信度 0.30 的条目与错误高度相关（`NoV 30` 0.30、`VOL. 01` 0.30），但 `GMT+8` 为 0.50 仍是幻觉，置信度只能作弱参考。

## 6. 对选题的直接影响（事实推论，非建议）

- Track 1 的赛道名与模型宣称的 "text rendering and layout" 强项对应，但**该强项在中英文之间分布不均**
- 评审方含腾讯混元，中文海报的容错空间更大
- 任何方案都必须**主动压制模型自加文字**，否则错字风险不可控
